# ShopMate – Full-Stack E-Commerce Website

ShopMate is a full-stack e-commerce web application where users can explore products,
search for products using AI, and place orders securely.

## Technologies Used

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT and HTTP-only cookies
- **Payments:** Stripe (Test Mode) and Cash on Delivery
- **AI Search:** Groq API

## Key Features

- Browse products and view product details.
- Search for products using AI-powered search.
- Add products to the shopping cart.
- Place orders using Cash on Delivery or Stripe test-mode payments.
- Secure user authentication and role-based access.
- Reset passwords through email.
- Manage products and orders through the admin dashboard.
- Manage stock safely during checkout.
